## 2. 快速跑起来

```bash
cd sleep-sim
# 方式一：HTTP（电脑调试用）
python3 -m http.server 8123 --bind 0.0.0.0
# 电脑访问 http://localhost:8123/m.html

# 方式二：HTTPS（手机语音必需：iOS/Android 浏览器在非安全上下文禁用麦克风）
# 先生成自签证书（把 IP 换成你的局域网 IP）：
openssl req -x509 -newkey rsa:2048 -keyout /tmp/sle-key.pem -out /tmp/sle-cert.pem \
  -days 365 -nodes -subj "/CN=10.0.118.86" -addext "subjectAltName=IP:10.0.118.86,IP:127.0.0.1,DNS:localhost"
python3 serve-https.py
# 手机访问 https://<局域网IP>:8443/m.html，首次需信任证书
```

注意：语音连续对话（SpeechRecognition）在 Chrome/Edge 桌面与 Android 可用；iOS Safari 的语音识别支持有限，文字聊天是兜底。

## 3. 功能全景（m.html v1.8）

**首开流程**：用户校验页（称呼必填 2-8 字；身份：自己睡/陪孩子睡，孩子需昵称+年龄 3-12 校验，失败红字+抖动）→ 穿越故事六幕（打字机叙事 + AI 场景图 + 选宠物两段式确认仪式）→ 主界面。用户信息存本地，问候语/宠物对话带称呼。

**掌机主控（Game Boy 形态）**：AI 插画机身 + 实时屏幕叠加层 + 隐形按键热区。十字键换宠物/调音量/菜单导航，A=夸/确认，B=聊天/取消，SELECT=屏内菜单，START=晚安。连点宠物 5 下 = 演示加速 ×20（路演用）。

**宠物养成**：五只宝可梦风宠物（胖丁/皮卡丘/小火龙/耿鬼/小眠，各有音高与机壳变色）；三围（心情/精力/亲密）+ 经验值 XP + 等级 LV + 称号（刚刚认识→形影不离）；摸头飘爱心、随机眨眼、睡觉说梦话、到点督促睡觉（四级念叨）；可改名（全局生效）。

**金币商城**：按时睡觉 +30、按时起床 +30、睡满一晚 +10、学习 +5~10、升级 +15。商城 6 件商品（晚安茶/草莓蛋糕/元气果汁/亲密铃铛/彩虹软糖/星空投影灯），即买即用，余额不足按钮置灰。

**成就系统**：10 枚徽章（初夜守护/三日同眠/一周之约/LV5/LV10/聊 10 轮/成语连胜 5/猜拳连胜 3/数羊 20/喂茶 5），解锁时金光+语音+10 XP，「我的」页成就墙。

**哄睡引擎（真音频）**：Web Audio 五层实时合成（底噪/纹理/遮蔽/细节/鸟鸣 + 卷积混响），6 个音景（雨夜木屋/海边小屋/林间篝火/纯底噪/夏夜虫鸣/老式风扇），定时关闭（15/30/45 分）。Agent 每 3 秒规则闭环：噪音遮蔽（真麦克风优先，模拟兜底）、睡眠阶段换挡、入睡后 20 分钟渐弱、夜醒陪护。

**晚安全流程**：日落屏幕灯效 → 音景淡入 → 模拟睡眠分期（清醒/浅睡/深睡/REM）→ 渐弱静默 → 日出唤醒（鸟鸣+晨光）→ 睡眠报告（评分+深睡占比+夜醒+遮蔽次数）→ 近 7 晚柱状趋势图。

**语音连续对话**：听→停听→想→说→继续听 的闭环，TTS 说话时停识别防自听，90 秒静默自动退出；支持语音指令（晚安/换音景/讲故事/呼吸/几点了）；填 OpenAI 兼容 API key（默认 Moonshot kimi-k2-0905-preview）后自由聊天，无 key 用内置温柔应答。

**学习乐园（主动/被动）**：主动——背单词（间隔重复+弱词本）/英语跟读打分/成语接龙（124 词库）/口算/古诗朗读/番茄钟；过睡觉点课本被"没收"。被动——睡前 25 秒宠物邀请"要不要复习一下"（按钮或语音"好/不用"应答），轻声读弱词+古诗；弱词本在「学习→被动磨耳朵」可视化。

**小游戏**：猜拳（连胜有奖）、数羊助眠（数到 20 自动关灯启动晚安）。

**闹钟硬件全家桶**：时钟屏保（床头钟模式：大字时间+日期+天气+宠物）、多闹钟/提醒（备注+开关+到点语音）、倒计时（十字键调分钟）、实时天气（wttr.in 免 key，中英文映射）。

**全程踩过的坑（写给接手的开发者）**：
- 用户审美要求极高：产品图/宠物图一律用 AI 生图，不要手写 CSS/SVG 画实物图
- 不要用 emoji（用户明确反感），用 CSS 图形或文字符号
- 语音在手机上必须 HTTPS（自签证书即可），http 局域网页面浏览器禁麦克风
- 无头 Chrome 截图最小宽度 500px，小于此会右侧裁剪——是工具假象不是布局 bug
- 批量字符串替换前先确认函数自身定义不在替换范围内（`PETS[curPet].name`→`nick()` 曾把 nick 自己改成死循环）
- 模板字符串拼接函数注意收尾括号（renderHist 曾漏 `}` 导致全脚本语法错误）

## 5. 技术架构

**零依赖单文件**：m.html 无框架、无构建、无后端，全部数据存 localStorage。打开即用，方便塞进任何壳（WebView/小程序 webview/Electron）。

**关键模块**（均在 m.html 内，按区块注释分隔）：
- 音景引擎：`RECIPES` + 五层 `scape`（base/tex/mask/detail/birds）+ `impulse` 混响；新音景只需加一个 recipe
- Agent 闭环：`setInterval(CONFIG.agentTickMs)` 里的 R1 噪音遮蔽 / R4 阶段换挡 / R5 渐弱计划
- 语音：`speak`（三层包装：TTS→说话时停识别→宠物蹦跳动画）、`startConvo/stopConvo`、`converse`（LLM 优先，localReply 兜底）
- 养成：`care`（mood/energy/bond/xp/lv）、`addXP/levelUp`、`addCoin/renderShop`、`checkAchv`
- 状态机：晚安 `goodNight` → `sunset` → `startSleepCycle` → `sunrise` → `finishSession`

**localStorage 键表**：`sle_user`（用户）/ `sle_pet`（宠物）/ `sle_petname`（改名）/ `sle_story`（故事已播）/ `sle_wake` `sle_bed`（作息）/ `sle_voice` `sle_vrate` `sle_vpitch`（嗓音）/ `sle_llm_key` `sle_llm_ep` `sle_llm_model`（大模型）/ `sle_nights` `sle_report` `sle_reports`（睡眠）/ `sle_xp` `sle_lv` `sle_coins` `sle_stats` `sle_achv`（养成）/ `sle_weak`（弱词本）/ `sle_alarms`（闹钟）/ `sle_passive`（睡前邀请开关）/ `sle_study_<日期>`（学习日数据）

## 6. 素材管线（AI 生图）

当前素材由 MiniMax image-01 生成（prompt 在会话记录里）。重制清单（用户指定换火山 Seedream 4.0，效果更好）：

1. 掌机机身高清版（640×960，2:3）
2. 五宠物 × 3 姿态（待机/开心/睡觉，384px 透明感）
3. 卧室夜景背景、学习乐园六图标、数羊场景背景

Seedream 调用方式（拿到 key 后）：
```bash
curl https://ark.cn-beijing.volces.com/api/v3/images/generations \
  -H "Authorization: Bearer $ARK_API_KEY" -H "Content-Type: application/json" \
  -d '{"model":"doubao-seedream-4-0-250828","prompt":"...","size":"2K"}'
```
生成后 PIL 裁水印/裁边，替换 `pets/` 同名文件即可，无需改代码。
