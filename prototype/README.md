## 它是什么

单文件手机 Web 应用（`m.html`）：零框架、零构建、零后端，全部数据存
localStorage，本地起个 HTTP 服务就能用——目的是**方便塞进任何壳**
（WebView / 小程序 webview / Electron）。

与固件仓库的分工：

| 固件（`app/mianyu`）验证过的 | 原型（本目录）补上的 |
|---|---|
| Agent 对话回路（语音进出、入睡判定后淡出不播报） | 电子宠物人格层：五只宠物、聊天、督促睡觉、夜醒耳语陪护 |
| 端侧噪声实时合成（Flash 0KB） | 六音景引擎 + Agent 每 3 秒闭环（噪音遮蔽 / 阶段换挡 / 入睡渐弱） |
| 4-7-8 呼吸光引导节拍器 | 完整晚安全流程：日落 → 睡眠分期 → 日出唤醒 → 报告与 7 晚趋势 |
| 手表两页界面（LVGL） | 首开用户校验 + 穿越故事六幕 + 掌机主控 + 六 tab 完整 App |

以及固件里没有的**经济层**：金币商城（按时睡觉 +30 / 按时起床 +30 /
睡满一晚 +10 / 学习 +5~10 / 升级 +15，6 件商品即买即用）、10 枚成就、
学习乐园（背单词 / 英语跟读 / 成语接龙 / 口算 / 古诗 / 番茄钟 + 睡前被动磨耳朵）。
**"睡觉能赚金币、金币能养它"——行为改变靠感情不靠自律，这是原型阶段验证的核心假设。**

## 怎么跑

```bash
cd prototype
python3 -m http.server 8200 --bind 0.0.0.0     # Windows 本机：py -m http.server 8200
# 电脑访问 http://localhost:8200/m.html

# 手机语音聊天必须 HTTPS（浏览器在非安全上下文禁用麦克风）：
python3 serve-https.py    # 证书缺失时自动探测局域网 IP 并生成自签证书（需 openssl）
# 手机访问 https://<局域网IP>:8443/m.html，首次需信任证书
# 证书生成在本目录（sle-*.pem，已 gitignore，私钥不入库）
```

注意：语音连续对话在 Chrome / Edge 桌面与 Android 可用；iOS Safari 的
语音识别支持有限，文字聊天是兜底。填 OpenAI 兼容 API key 后自由聊天，
不填用内置温柔应答（key 只存本机）。

## 路演用：演示速览（2026-11-03 新增）

**连点宠物（或圆盘）5 下**，把一整夜压进约 25 秒演完：

```
日落陪伴 → 浅睡 → 深睡 → 噪音遮蔽（52dB）→ REM → 夜醒耳语陪护
→ 日出唤醒 → 自动生成睡眠报告并跳到报告页
```

再连点 5 下可中途退出（退出不生成报告）。实测输出：评分 90 / 总时长 7h12m /
深睡 31% / 夜醒 1 / 遮蔽 1。

为什么不是"×20 快进"：`demoSpeed` 只提速计时器，而日出的触发点是真实时钟
（明早 07:00），一整夜除以 20 仍要几十分钟，路演等不起。所以另做了一条
脚本化的速览时间线（`m.html` 里的 `demoTour()`），演出用的报告按一整夜生成
（`session.demo` 标记），不会被算出"3 分钟睡眠"。

### 本轮（2026-11-03）修掉的三个真 bug

| 问题 | 现象 | 根因 |
|---|---|---|
| 报告评分溢出 | 圆环里显示 `67.08333333...` 一长串，压出边界 | 评分公式没取整，提前结束睡得越短小数越长 |
| 整页被染橘色 | 演示/日出结束后全 App 蒙一层落日色 | `sunrise()` 只清 `ovDark`，没清 `ovSunset`；且日落渐暗的长间隔未停 |
| 日出后按钮状态错 | 一夜结束后按钮仍显示「结束今晚」 | `sunrise()` 收尾没复位按钮文案 |

另外给 `finishSession` 加了防重入（`s.done`），避免「日出 + 手动结束」重复计夜、
重复发金币。
