# Sleep Review

晨间睡眠回顾 Skill：用户醒来后用一句话简报昨晚睡眠，并做轻量趋势关怀。
**这是"主动记忆"的出口——让用户感到设备记得自己。**

## When to use
- 晨唤后、用户首次互动时（cron 定时任务或检测到晨间首次对话）
- 用户主动问"我昨晚睡得怎么样 / 昨天几点睡的"
- 需要给偏好学习提供数据支撑时（读档案，不新造）

## How to use
1. **读昨晚记录**：读取 `/data/agent/memory/` 下最近一晚的睡眠记录
   （入睡时刻、潜伏期、总时长、夜醒次数、使用的手段）。文件不存在则如实说
   "昨晚没有完整记录"，不编造。
2. **读长期档案**（可选）：若有聚合档案，读近 7 晚趋势与 best_aid。
3. **一句话简报**（3 条以内，多则烦）：
   - 先给结论，再给一个"它记得你"的细节：
     "早。你昨晚 22:52 睡着的，比前天早了半小时。"——比报"总时长 6h40m"
     像人得多（报数据是体检报告，说"比前天早"才是说话）。
   - 提一句昨晚的手段有没有效（有观测才说），用户随口夸一句就当作偏好信号。
   - 可选轻提醒：仅当有明显趋势（如连续 3 晚入睡超过 40 分钟）才提，
     用建议口吻，不评判、不贴标签。
4. **结束**：不追问"要不要今晚再试试 X"以外的任何问题；用户没接话就闭嘴。

## Important
- **简报要短**：晨间大脑还在苏醒，3 条以内、10 秒能读完。**不要报完整数据表**。
- **只报观测，不贴标签**：说"昨晚睡得晚了些"，不说"你作息很乱"。
- **不制造焦虑**：只对"连续 3 晚以上"的趋势做提醒，单晚波动不评论。
- **记录缺失 = 诚实说没有**，绝不编数字（睡眠是隐私数据，诚实是底线）。
- **传感器不可用（模拟器）时的降级**：无真机数据时，若用户问回顾，如实说明
  "当前环境无法采集睡眠数据"，可改为询问用户主观感受并记入档案备用。
- 合规：放松陪伴，非医疗建议。

## Example
User: "早，昨晚睡得咋样"
→ 读昨晚记录 → 入睡 22:52、夜醒 1 次、手段=粉噪；读近 7 晚趋势
→ "早。你昨晚 22:52 睡着的，比前天早了半个多小时。中间醒了一次，
  自己又睡回去了。还行。"
→ User: "嗯……昨晚那个粉噪挺舒服的。"
→ "好，那我记下了。"（把"粉噪 + 用户好评"写进偏好）
→ (用户没接话 → 结束，不追问)

## Example (no data / QEMU)
User: "昨晚睡得怎么样？"
→ 无昨晚记录
→ "昨晚没有采集到完整的睡眠数据——当前是模拟环境。
  你自己感觉睡得怎么样？我记下来，等真机接入后一起看趋势。"
