# Sleep Onset

引导用户进入睡前放松流程的主动哄睡 Skill：到点后轻声开场、播放舒缓噪声、
按检测状态渐弱淡出。**核心原则：声音是服务不是打扰，全程可被一句"暂停"打断。**

## When to use
- 到用户设定的睡前时间（cron 定时任务触发，默认 22:30）
- 用户主动说"我要睡了 / 准备睡觉 / 哄我睡觉 / 放点白噪音"
- 入睡判定模块上报"长时间未入睡"，需要换策略

## How to use
1. **先确认环境**：`get_current_time` 取当前时间。若距用户计划睡前时刻 >15 分钟，
   只轻声提醒不启动完整流程；在窗口内才进入引导。
2. **读记忆（决定今晚用什么）**：
   - `read_file /data/agent/memory/MEMORY.md` —— 若存在且含近期记录，
     读出 `best_aid`（入睡最快的手段）与今晚建议，优先用用户历史上最快的手段。
   - 文件不存在/为空则跳过，用默认顺序。
3. **开场白**（语速放慢，1 句话即可，不啰嗦）：
   - 参考话术（挑一种，别全说）：
     "十点半了。今晚早点躺？"（提醒式，说完就等回应）
     "躺下吧，声音我调好了。"（用户已躺下）
     "今天换个粉噪，比棕噪轻。"（用记忆做过偏好轮换时）
   - 说话像人：短句、不报菜单、不喊"祝您晚安"。
   - 用户没接话就不追问，灯暗回去，不打扰。
4. **播放助眠噪声**：
   - 优先本机合成的零存储噪声（白/粉/棕噪，见系统能力），
     其次 `music_play` 播放本地 WAV 引导语或 CC0 音源。
   - 起始音量 **≤ 40%**（music_set_volume 40），绝不以大音量开场。
5. **启动入睡监测**：通过系统入睡判定模块持续观测呼吸规律度与体动（无需用户
   操作、不打断）。**不可用时的降级**（模拟器/无传感器）见 Important。
6. **入睡后淡出**：判定入睡（或超时 30 分钟仍未入睡）后，
   进入音量淡出曲线，在 60~90 秒内平滑降至 0 并停止。淡出期间**不播报、不确认、
   不聊天**——任何一句"晚安"都可能把人吵醒。
7. **收尾动作**：把今晚记录（开始时间/采用手段/入睡潜伏期/淡出时刻）写入
   `/data/agent/memory/` 下的当日睡眠记录，供晨间回顾与偏好学习使用。

## Important
- **音量为王**：全程音量只降不升，除非用户明确要求。深夜音量突变=惊醒源。
- **少说多做**：开场 1 句话，引导过程零播报。用户要的是安静，不是陪伴聊天。
- **尊重打断**：用户说"停 / 别放了 / 太吵了"→ 立即停止播放并回复一句简短的
  确认，然后不再打扰。
- **诚实的传感器降级**：若当前环境无麦克风/IMU（如模拟器），如实说明：
  "当前环境无法检测你的入睡状态，我按 30 分钟自动淡出。" 然后照常淡出收尾。
  **不得**谎报"已检测到你入睡"。
- 合规：这是睡前放松陪伴，不是医疗行为。**不承诺治疗效果、不替代药物**。

## Example
User: "躺下了……今天有点睡不着。"
→ read_file MEMORY.md → 昨晚用的棕噪，这次换粉噪（避免连续同一种）
→ "那就先不睡，听会儿声音。今天换粉噪，你昨晚听的棕噪。"
→ 播放粉噪，音量 30%；呼吸引导灯同步亮起
→ "来，跟着光——吸……停……慢慢呼。"
→ 入睡判定 → 22:52 判定入睡 → 20s 淡出（不说话，灯同时灭）
→ 写入当日记录 → (静默)

## Example (sensor-less / QEMU)
User: "我要睡了"
→ 播放粉噪，音量 30%
→ 检测模块不可用
→ "当前环境无法检测入睡状态，我 30 分钟后自动调低音量。晚安。"
→ 30 分钟后淡出停止
