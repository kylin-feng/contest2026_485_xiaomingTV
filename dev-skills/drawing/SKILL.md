# 图纸设计 · 模型画渲染，代码画标注

**一句话：别指望图像模型画准尺寸；它在"好看"上无敌，在"精确"上一无是处。**

## When to use

- 要出产品三视图（正/侧/俯）带长宽高
- 要把概念渲染变成能递给结构工程师的规格图
- 生图上的文字总是乱码、尺寸总是对不上

## 核心分工（这条不遵守必翻车）

| 谁做 | 做什么 |
|---|---|
| 图像模型（Seedream / 即梦 / MJ） | 写实渲染：材质、光、阴影、形态 |
| 代码（Pillow / matplotlib / SVG） | 尺寸线、箭头、数字、图例、规格表、版式 |

本案实测：让模型直接"画出带尺寸标注的三视图"，数字 100% 是乱码或错位；
改成"模型只出三张干净渲染 + 脚本标注"，一次成型。

## How to use

### 第 1 步：写正交视图提示词

**共同前缀**（保证三张图是同一个产品）：

> Photorealistic studio product photograph of a `<形态>` `<产品名>`, `<直径>`, `<上/下半球材质>`,
> separated by `<中缝材质>`, `<底部>`. No screen, no camera, no logo, no text.
> Soft diffused studio lighting, pure white background.

**逐视图后缀**（关键，缺一句角度就偏）：

| 视图 | 后缀要点 |
|---|---|
| 正视图 | `Straight-on front elevation, camera exactly at the height of center, zero perspective so the object reads as a PERFECT CIRCLE. No top surface visible.` |
| 侧视图 | `Exact 90-degree side profile, perpendicular to front, no three-quarter angle.` |
| 俯视图 | `Camera EXACTLY 90 degrees above, looking straight down. Only a PERFECT FLAT DISC is visible — no side surface, no height. Concentric rings, button exactly at center.` |

实操经验：
- **写"只能看到什么"比写"不要什么"有效**。俯视图连试 4 轮才成，
  转折点是改成"画面里只有一个正圆，看不到侧面"。
- 每次生成后**必须看图**再决定下一步；不要连续生成 5 张再挑。
- 尺寸用 2K 出图，标注完再降采样；1K 放大后织物纹理糊。

### 第 2 步：背景归一到纯白（必做）

渲染底色很少是纯白（常是 238–252 的带噪渐变），直接贴到版面上会看到灰方块。

```python
# 边缘白平衡 + 白点收敛：把背景压到 255，同时保留阴影层次
edge = np.concatenate([a[:6].reshape(-1,3), a[-6:].reshape(-1,3),
                       a[:,:6].reshape(-1,3), a[:,-6:].reshape(-1,3)])
b = np.median(edge, axis=0)                     # 背景水平
a = np.clip(a * np.clip(255.0/b, 1.0, 1.35), 0, 255)
mn = a.min(axis=2, keepdims=True)
t = np.clip((mn - 238.0) / 8.0, 0, 1)           # 238 以下保留，246 以上推纯白
a = a * (1-t) + 255 * t
```

### 第 3 步：比例定标（决定图纸能不能看）

三视图必须**同一个尺度**，否则一眼假。

- **球体/圆柱**：取最宽一行（赤道）的像素宽度 = 直径，按此缩放
- **不要用裁切框宽度定标**：投影和阴影会把框撑宽，导致球偏小
- 水平方向收到赤道宽度再缩放，三视图球径就一致了

### 第 4 步：标注规范

- 单位只在标题区写一次"单位：mm"，不要每个数字后都加 mm
- 直径用 **Φ**（U+03A6），别用 ⌀（U+2300）——微软雅黑没有这个字形，会变豆腐块
- 尺寸线：两端箭头 + 细灰延伸线；数字压在线上方，背后留白避免压字
- 特征标注别拉长引线跨过主体（会压住产品），改用**编号圆点 + 图例**
- 页脚必写口径：`概念渲染，尺寸为设计目标值，非加工工程图`

### 第 5 步：版面骨架（2520×1880 可打印）

```
标题 + 一句话描述 + 单位          ← 0-210
──────────── 分隔线 ────────────
正视图     侧视图     俯视图        ← 视图按同一基线对齐
图例 ①②③④                        ← 编号说明，两列
──────────── 分隔线 ────────────
规格表（3 列 × N 行）              ← 尺寸/材质/传感器/接口/重量
页脚：口径与免责
```

## 交付物

- `xxx_三视图.png`（≥2400px 宽）+ 同名 `.pdf`（300dpi 可打印）
- 源脚本（可重新生成，别只交图）

## 反模式

- ❌ 让模型直接写尺寸数字（必乱码）
- ❌ 三张图分别定标（球一大一小）
- ❌ 把设计目标值写成实测值
- ❌ 用 ⌀/✓/★ 等字体缺字字符
- ❌ 只交图片不交脚本（改一个名字就得全部重画）

## 验收门

- [ ] 三视图球径/宽度一致，底边对齐
- [ ] 背景纯白无灰块
- [ ] 所有数字与选型表一致
- [ ] 无豆腐块字符
- [ ] 有单位、有口径页脚
- [ ] 交付 PNG + PDF + 生成脚本
