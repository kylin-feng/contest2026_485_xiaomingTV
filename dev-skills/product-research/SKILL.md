# 产品调研 · 三张图定生死

**一句话：先证明赛道能赚钱，再证明这个位置没人站，最后证明你比对手强。**

## When to use

- 刚有一个想法，要先判断值不值得做
- 路演/立项材料需要市场章节
- 竞品分析变成"列了十家公司"但说不出差异

## How to use

### 第 1 张图：赛道验证（这个生意成立吗）

只找**两类证据**：

1. **有人已经赚到钱**：营收、订阅收入、会员数、留存率
2. **钱是怎么赚的**：卖硬件？订阅？B 端按床位？

输出格式（表格）：公司 | 营收 | 收入结构 | 数据来源 | 数据日期

> **时效必须核**。本案真实教训：初稿写"Oura 2025 财年 9.08 亿美元"，
> 决赛前复核发现已更新为"近 12 个月 12 亿美元、同比 +74%、会员留存 85%"。
> **超过半年的数据，交付前必须重新搜一次**，搜到就用新的，搜不到就标注"截至 X 月"。

### 第 2 张图：生态位地图（我站哪）

把目标生态**按层拆**，每层标出：谁占了、做得怎么样、是不是通用件。

```
编排层 · 大脑        ← 完全空白（机会）
干预层 · 灯/声/温/帘  ← 通用件，无专职产品
穿戴层 · 戒指        ← 强玩家
感知层 · 雷达        ← 强玩家
床上层 · 床垫/枕头    ← 强玩家
```

判定标准：**能在一句话里说清"这层为什么空、为什么是我们"** 才算找到位置。
本案的说法："别的层都有人，唯独没人做那个在正确时间做正确动作的大脑。"

### 第 3 张图：竞品矩阵（我强在哪）

维度要能拉开差距，别用"价格/功能/服务"这种谁都填得满的项。推荐：
价格 | 核心能力 | 感知能力 | 生态联动 | 个性化 | **情感价值**

最后一列往往是空白——那就是你的差异点。

## 交付物

```
docs/<项目>-调研_<日期>.md
  1. 三条结论（每条约 40 字，能被直接念出来）
  2. 赛道验证表（含来源与日期）
  3. 生态位地图（用表格或 ASCII，不依赖图片）
  4. 竞品矩阵（你自己的那一列加粗）
  5. 数据缺口清单（哪些数没找到、打算怎么补）
```

## 反模式（见到就删）

- ❌ 市场"千亿级"却没有一个具体公司名
- ❌ 竞争对手只写"竞品 A/B/C"
- ❌ 把行业报告的预测当已发生事实
- ❌ 自己编一个"用户调研：87% 的人愿意付费"
- ❌ 数据没有日期——半年后的数字就是错数字

## 验收门

- [ ] 每个数字后面有来源 + 日期
- [ ] 生态位图能指着一格说"这里空着，所以是我们"
- [ ] 竞品矩阵最后一列不是人人都有的能力
- [ ] 有三条能直接念出来的结论
- [ ] 明确列出"还没找到的数据"
