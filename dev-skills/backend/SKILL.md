# 后端 / 固件 · 让算法在 16MB Flash 上活下来

**一句话：能跑通的标志不是"编译过了"，是"有实测数据能贴出来"。**

## When to use

- 写设备端业务逻辑（状态机、规则引擎、音频合成）
- 打通 串口 / 音频 / 屏幕 / 触摸
- 算法要上 MCU（没有 DSP、没有 IMU、内存紧张）
- 要写"能被评审复现"的测试

## 架构原则：核心层与平台层切开

```
core/        纯 C，不调用任何 OS 时间/内存函数，可 PC 上单元测试
hal/         平台适配（真机后端 + PC 模拟后端）
ui/          界面（LVGL）
main.c       主循环：只做调度
```

**时间由调用方喂**（`tick(delta_ms)`），核心层因此能在 PC 上完整跑测试，
换平台只换画法/IO，算法一字不改。本案 465 条断言就是这么来的。

## 真机排障铁律（每一条都是血）

### 1. 注册顺序 > 一切自检

本案：屏幕"间歇性不发光"，查了 5 轮 8 个假设才发现根因不在驱动——
一段约 54 秒的自检（6×8s ALLPON）跑在 `lcddev_register()` **之前**，
开机一分多钟内 `/dev/lcd0` 不存在，界面线程死等，看起来完全像"屏坏了"。

> 规则：**先注册设备，再跑自检**；自检必须能被宏关掉，默认关闭。

### 2. 引脚复用表必须上电

本案：PA10 同时是屏幕电源使能与功放使能。任何把它拉低的代码都会让屏幕掉电，
且**没有任何路径会重做面板上电**——于是"屏幕又黑了"。

> 规则：动手前先列"一个引脚几个用途"，冲突项要在代码里加注释 + 断言。

### 3. 听不见 ≠ 没在放音

本案：喇叭不出声，用**声学回环对照**定性——功放开/关各录一次环境音，
算相关性 B/C=0.83（几乎一样），说明麦克风收到的是板内电耦合，不是声波。
最后发现是**板上喇叭座空着（缺件）**，不是软件问题。

> 规则：音频故障先做回环对照，再怀疑驱动。

### 4. 每帧都在重绘 = 帧率杀手

本案：`lv_label_set_text()` 每秒调 10 次，每次都无条件标脏整屏并 free/malloc 文本缓冲，
帧率 5fps。改成"文本真变了才写"，脏区 275788 → 4954 px/帧，5fps → 25fps。

> 规则：任何 UI 更新前先判"值变了吗"。

### 5. 后到设备要运行期补挂

本案：触摸芯片 FT6146 比 LVGL 晚 23 秒才注册 `/dev/input0`，
LVGL 启动时 `indev=0`，点屏幕没反应。改成主循环里探测节点，出现就补挂。

> 规则：不要假设所有外设在上电瞬间就绪。

## 串口语音链路（无 WiFi 板子的通用解）

```
MEMS MIC ─► 板子 ─串口 1Mbps─► PC 网关 ─WebSocket─► LLM
              ▲                    │
              └── DAC + Class-D ◄── TTS ◄──┘
```

帧格式（自找回边界）：

```
A5 5A | type | flags | seq | len(u16 LE) | payload | crc16(u16 LE)
crc16 = CRC16-CCITT-FALSE，覆盖 type/flags/seq/len/payload
```

- 开机先跑协议自检（CRC 向量 / 组帧 / 容错 / 解析器），不过就不开链路
- 实测指标写进报告：20 秒上行 672→704 帧、**丢帧 0**
- 坑：nsh 阻塞在 console 上会抢走下行的 PCM，需要独占串口或做通道交还

## 资源受限下的算法取舍

本案要"用呼吸判断入睡"，目标板**没有 DSP、没有板载 IMU、16MB Flash**：

- 不做 FFT，走时域：100ms RMS 包络 → 降采样到 10Hz → 30 秒窗归一化自相关
- 在 0.15–0.5Hz（9–30 次/分）找峰：**峰高=规律度，峰位=呼吸率**，加迟滞防抖
- 算力：每 2 秒一轮、约 1.8 万次乘加、占空比 < 0.05%
- 夜醒用"**规律度塌缩**"判（醒了就没有周期性呼吸）

噪声也不用存音频：xorshift32 + Kellet 滤波实时合成，**Flash 占用 0KB**。

## 测试门（不接受"应该没问题"）

| 门 | 标准 |
|---|---|
| 单元测试 | 核心层断言全绿（本案 465 条），`make test` 可复现 |
| 混淆矩阵 | 用合成信号跑出 TP/FN/FP/TN，并注明"合成信号" |
| 链路自检 | CRC / 组帧 / 容错 / 解析器四项开机自检通过 |
| 真机心跳 | 打印 `putarea/wrram/done/timeout`，要求 `done == wrram` 且 `timeout == 0` |
| 整晚闭环 | 把一夜压缩到十几秒跑完，日志可查 |
