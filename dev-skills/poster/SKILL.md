# 海报 / 路演视觉 · 让人一眼看懂一句话

**一句话：一页只讲一个论点；能被念出来的一句话，比十个要点值钱。**

## When to use

- 路演 PPT（8–15 页）
- 产品海报 / 宣传图
- 答辩材料、一页纸 BP

## 第 1 步：先定"一句话"

每页写一句**能直接念出来的话**，再排版：

- ✅ "不是白噪音音箱，而是整夜值守的哄睡 Agent"
- ✅ "别人做单品，我们做会陪伴的编排中枢"
- ❌ "产品功能介绍"（不是论点）
- ❌ "市场分析"（不是结论）

无法念出来的标题 = 这一页还没想清楚。

## 第 2 步：定视觉系统（三个决定）

1. **配色从产品里取**，不要从网上抄：
   - 底色（60-70%）/ 主色 / **一个强调色**（5-10%，只给最重要的数字或结论）
   - 本案：深夜 `#0D0E1A` + 靛卡 `#161728` + 陶橙 `#E8875A`（产品按钮色）
2. **字体用系统自带的**：Windows/macOS 都有的是 微软雅黑 / 苹方。
   用了只有你机器上有的字体，评委电脑上会悄悄替换，版式全崩。
3. **选一个母题重复**：例如"超大数字 + 细线分隔"。
   母题可以是圆角卡片、超大数字、留白节奏——**不要用彩色横条/侧边条**（AI 味最重的标记）。

### 深/浅结构

- 封面、结尾用深底（情绪）
- 内容页用深底或浅底都行，但**全篇统一**
- 本案全深色：因为产品是夜间场景，深色本身就是叙事

## 第 3 步：版式骨架

```
┌──────────────────────────────────┐
│ 小节标号 / 中文标签        （左上，橙）│
│ 标题（一句话论点，34-40pt）         │
│ 副标题（补充条件，16-18pt，灰）      │
│                                  │
│  ← 主视觉：图 / 表 / 流程 / 大数字 →  │
│                                  │
│ 来源与口径（12pt，灰，左下）  页码（右下）│
└──────────────────────────────────┘
```

规则：
- 一页一个焦点。主视觉占 50%+，其余是配角
- 正文最小 20-24pt（投影后排数清楚），脚注最小 12pt
- 左右边距 ≥ 0.5"，块间距 0.3–0.5"，全篇一致
- **不要大面积空白**：用真实内容填（放大数字/图/引一句原话），不要用装饰块填

## 第 4 步：数据与口径（评委必看）

- 每个关键数字带**来源 + 年份**（写在页面底部小字）
- 估算值必须标"示意估算"，不要伪装成实测
- 收入构成这类图，用"示意"两个字能省掉一场追问

> 本案：Hatch 2 亿美元（Inc., 2026-05）、Oura 近 12 个月 12 亿美元（Sacra/Yahoo Finance）、
> Sleepal κ=0.695（36氪）、3 亿人（中国睡眠研究会）。

## 第 5 步：配图

- **产品图用真实截图/渲染，不要用示意图假装是产品**
- 生成图统一处理背景（见 `dev-skills/drawing`）
- 深色版面上不要贴带浅色底的图片（会出现"便利贴"方块）
- 图片永不拉伸：按比例裁切（cover），不要改宽高比

## 第 6 步：两轮视觉审查（别省）

1. **机器渲染**：LibreOffice 转 PDF → 逐页 PNG
2. **逐页看**，专门找这七类问题：
   文字溢出/裁切、图文重叠、对比度不足、图片变形、间距不一致、大面积空白、字体缺字（豆腐块）
3. 改完**再渲染一轮**复核——修一处经常带出新的一处

> 本案第一轮 15 页里 6 页被打回（箭头压卡片、横条对比度不足、左右栏文字叠压、时间轴溢出边界…），
> 修完第二轮才全过。

## "AI 味"负面清单（见到就删）

- ❌ 标题下的装饰横线
- ❌ 彩色横条 / 侧边条 / 卡片边缘色带
- ❌ 每页都一样的 2×2 卡片网格
- ❌ emoji 当图标
- ❌ 默认蓝 + 渐变
- ❌ 正文居中
- ❌ 一页塞 8 个要点
- ❌ 用"赋能/闭环/抓手"这类空词（除非你真在说闭环）

## 交付物

- `xxx.pptx`（可编辑，每页带演讲者备注讲稿）
- `xxx.pdf`（评审直接看）
- `source/build.js`（生成脚本 + 素材，能重出）
- `逐页讲稿手册.md`（时间轴 + 每页讲稿 + 限时压缩版）

## 验收门

- [ ] 每页标题是一句能念出来的话
- [ ] 全篇颜色/字体/间距统一
- [ ] 每个数字有来源，估算有标注
- [ ] 无溢出、无重叠、无豆腐块、无拉伸
- [ ] 有讲稿备注，按页计时能对上总时长
- [ ] 交付 pptx + pdf + 生成脚本
