# 2026-09-06 · 呼吸引导模块、UI 与演示脚本

## 1. 呼吸引导 `src/mianyu_breathe.c`
- **任务**：4-7-8 呼吸法的时序生成（吸气 4s / 屏息 7s / 呼气 8s）。
- **AI 参与**：生成状态机骨架与波形映射。
- **人工确定**：相位切换处做插值而非跳变（避免光晕突跳）；循环次数可配；入睡后必须能立即中止并归零。
- **产出**：`mianyu_breathe.c/.h`、`tests/test_breathe.c`
- **校验**：41 断言全绿（波形/边界/循环三类）。

## 2. 呼吸光晕 UI `app/ui/breathe_lvgl.c`
- **AI 参与**：生成 LVGL 动画与 PWM 背光联动代码。
- **人工确定**：**跨线程更新一律 `lv_async_call()`**（LVGL 非线程安全，而哄睡恰是"后台淡出 + 前台光晕"并发）；
  UI 用相对布局（flex/百分比）而非绝对坐标——模拟器 194×368 与真机 390×450 分辨率不同，绝对坐标必然返工；
  ePicasso GPU 走条件分支（PR 合入则启用，否则软件渲染 + 降帧，核心功能不依赖动画流畅度）。
- **产出**：`app/ui/breathe_lvgl.c`、`outputs/眠语_呼吸光晕预览.html`（浏览器可跑的等价预览）

## 3. 整晚演示脚本
- **AI 参与**：生成 22:30 → 入睡 → 夜醒 → 晨间回顾的对话与状态流转脚本。
- **人工确定**：夜醒触发 30 分钟内不重复；晨间回顾 ≤3 条不啰嗦；全程无"治疗/疗效"表述（合规）。
- **产出**：`outputs/眠语_整晚对话演示脚本.html`
