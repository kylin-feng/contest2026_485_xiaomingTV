# AI Coding 日志

本目录记录本作品在 AI 辅助下的真实开发过程，用于大赛「AI 开发」评分维度核验。

## 记录方式（如实说明）

- 开发工具：WorkBuddy / AI Coding Agent（会话式协作，非逐字 prompt 存档工具）。
- 本目录内容为**按模块归档的协作记录**：每一条含「日期 / 任务 / AI 参与方式 / 产出 / 人工校验结果」。
- 其中「AI 参与方式」是对当次指令意图的**摘要**，非逐字原文；**产出代码、日志与测试结果均为仓库内真实文件**，可对照 `src/`、`tests/`、`docs/测试记录表.md`、`docs/真机运行证据_20260914.md` 核验。
- 若评委需要原始对话，可补充导出至 `logs/raw/`（本工具会话可全量导出）。
