## 这份导出的口径

- 用户指令：`<user_query>` 里的原文整段保留，单条超 8000 字截断。
- 助手回复：正文原文保留，单条超 4000 字截断，末尾标 `...(截断)`。
- 模型思考：只留每条前 200 字的节选，不是全文。
- 工具调用：留工具名和关键参数摘要；`Write` / `Edit` 只留路径和开头一小段预览，不整篇贴代码。
- 工具结果：每条最多 1000 字；base64、二进制、超长整块内容换成一句占位说明。
- 没有导入的：模型侧 `providerData`、文件快照（`snapshot`）、图片引用块。
  原始 jsonl 90 MB 里有 65 MB 是这几样，跟对话内容无关。
- 脱敏：出现过的 GitHub 令牌、API key、云机密码在导出时替换成 `<已脱敏>`。
  本机代理 `http://127.0.0.1:7897` 不算敏感，原样保留；云机的地址和端口也原样保留，只把口令换掉。
  个别命令行示例里 `password=...` 后面的内容跟着口令一起被替换，读起来会有点断，
  原始 jsonl 里是完整的。
- 原始 jsonl 没改动过，要逐字核对可以直接看：
  `C:\Users\Administrator\.workbuddy\projects\c-Users-Administrator-WorkBuddy-2026-09-08-18-49-22\ad456617-873c-4610-aa41-ceb8d311c187.jsonl`

  以及同目录下的子代理记录
  `...\ad456617-873c-4610-aa41-ceb8d311c187\subagents\agent-75c13b39.jsonl`。

## 09-16 之后那几天（Kimi Code）的口径

与上面完全一致，只是源格式不同（Kimi Code 存的是 `wire.jsonl` 事件流：
`turn.prompt` / `content.part`(text|think) / `tool.call` / `tool.result`）。
导出脚本 `tools/export_ai_logs.py`，重导一条命令：

```bash
python tools/export_ai_logs.py --list      # 先看本机有哪些会话（★标记本作品的）
python tools/export_ai_logs.py             # 按作品关键词挑会话并导出
```

三个额外的处理，都是踩过才加的：

- **只导本作品的会话**：按首个用户指令里的关键词筛（小鸣TV / 安眠科技 / openvela /
  contest2026 / mianyu / 眠语），避免把别的项目导进来稀释日志。
- **口令连片段一起脱敏**：排查时会在命令里写 `grep "<口令片段>"` 这种**片段**做核查，
  单个片段看着不像密钥、几段凑起来却能还原，所以脚本把密钥的**所有长度≥3 的子串**
  一并替换成 `<已脱敏>`。核对方法：把口令的任意片段（含前几个字符）grep 一遍，应为 0。
- **剥掉 NUL、行尾统一 LF**：工具输出里混进来的二进制（串口原始数据、base64 块）
  会带 NUL，带 NUL 的文件会被多数工具当成二进制、`Read` 直接拒读 —— 那份日志等于白导。
