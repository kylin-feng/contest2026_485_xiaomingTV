## 这份导出的口径

- 用户指令：`<user_query>` 里的原文整段保留，单条超 8000 字截断。
- 助手回复：正文原文保留，单条超 4000 字截断，末尾标 `...(截断)`。
- 模型思考：只留每条前 200 字的节选，不是全文。
- 工具调用：留工具名和关键参数摘要；`Write` / `Edit` 只留路径和开头一小段预览，不整篇贴代码。
- 工具结果：每条最多 1000 字；base64、二进制、超长整块内容换成一句占位说明。
- 没有导入的：模型侧 `providerData`、文件快照（`snapshot`）、图片引用块。
  原始 jsonl 90 MB 里有 65 MB 是这几样，跟对话内容无关。
- 脱敏：出现过的 GitHub 令牌、API key、云机密码在导出时替换成 `<已脱敏>`。
  本机代理 `http://127.0.0.1:7897` 不算敏感，原样保留；云机的地址和端口也原样保留，只把口令换掉。
  个别命令行示例里 `password=...` 后面的内容跟着口令一起被替换，读起来会有点断，
  原始 jsonl 里是完整的。
