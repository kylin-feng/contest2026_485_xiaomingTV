# 决赛当天检查清单（打印一页）

> 版本 2026-11-03 · 配套 `演示脚本.md` / `答辩预案.md` / 路演 PPT

## T-60 分钟 · 设备

- [ ] 电脑充满电 / 插电；关闭系统通知（勿扰模式）、关闭自动更新弹窗
- [ ] 手机与电脑连同一 WiFi；**手机上看一眼信号强度**（现场人多会挤 2.4G）
- [ ] 手机音量调到 70%，媒体音量独立确认一遍
- [ ] PPT 用**本地文件**打开（不要用浏览器在线版），确认字体没变形
- [ ] 备用：PPT 的 PDF 版放在桌面同一文件夹

## T-30 分钟 · 演示环境

```bash
cd prototype
py -m http.server 8200 --bind 0.0.0.0        # Windows
python3 -m http.server 8200 --bind 0.0.0.0   # Mac/Linux
```

- [ ] 电脑访问 `http://localhost:8200/m.html` 能打开
- [ ] 手机访问 `http://<电脑IP>:8200/m.html` 能打开（用 `ipconfig` 查 IP）
- [ ] 需要演示语音时：`py serve-https.py` → 手机开 `https://<电脑IP>:8443/m.html`
      → 首次点"继续访问"信任证书 → 页面正常
- [ ] 页面**清一次存档**（控制台 `localStorage.clear()` 后刷新），确保从首开校验开始
- [ ] 连点宠物 5 下，确认「演示速览」能跑（跑完会跳到报告页，然后清存档恢复）

## 三条绝不说

1. 不说"我们解决失眠"——消费电子品，不做医疗宣称
2. 不说"睡眠分期准"——原型是模拟、固件是合成信号验证，真人标定还没做
3. 不编获客/转化/留存数字——没验证就说没验证
