# 现场演示脚本（90 秒版）

配套视频：`prototype_demo.webm`（21.7 秒自动录制：首开校验 → 故事 → 主控 →
换宠物 → 学习 → 商城）。现场演示按下面的路径走，说辞已按时间轴排好。

## 演示前准备（上场前 5 分钟）

```bash
cd prototype
python3 -m http.server 8200 --bind 0.0.0.0
# Windows 本机用：py -m http.server 8200 --bind 0.0.0.0
```

- 电脑演示：浏览器开 `http://localhost:8200/m.html`，开发者工具切手机视图（宽 500+）
- 手机演示（更能打动评委）：同一 WiFi 开 `http://<电脑IP>:8200/m.html`；
  要演示**语音聊天**必须 HTTPS：直接 `python3 serve-https.py`（Windows 用 `py`）——
  证书缺失时自动探测局域网 IP 并生成自签证书，手机开 `https://<电脑IP>:8443/m.html`
  并信任证书（2026-11-03 已在本机实测返回 200）
- **先清一次存档**（演示首开流程需要）：页面控制台执行 `localStorage.clear()` 后刷新
- 兜底顺序：真机手机 → 电脑浏览器 → 本目录 webm 视频 → PPT 第 5/6 页截图

## 90 秒路径与说辞

| 时间 | 操作 | 说（大意） |
|---|---|---|
| 0-10s | 首开校验页：输入称呼，点「校验身份 · 开始穿越」 | "第一次打开不是表单，是一段穿越回 2099 年眠屿星的故事——孩子会想把它走完" |
| 10-20s | 故事打字机播 1-2 句，点「跳过」 | "2099 年，失眠成了人类最大的流行病——这是产品的世界观" |
| 20-40s | 掌机主控页：指给评委看宠物三围、AGENT 值守动态；点宠物头像换一只 | "住在一台复古掌机里，心情精力亲密三围实时在养；Agent 每 3 秒巡一轮，现在显示待命中" |
| 40-55s | 点「开始晚安」 | "日落灯效、音景淡入、睡眠分期——整夜值守从这里开始"（现场安静的话可以听完第一句耳语） |
| 55-70s | 底部切「音景」tab | "六个音景全部是实时程序合成，不是录音循环，Agent 会跟着睡眠阶段换挡" |
| 70-85s | 切「商城」tab | "按时睡觉 +30 币、按时起床 +30 币，金币买晚安茶喂它——行为改变靠感情，不靠自律" |
| 85-90s | 回主控，收 | "这就是闭环：睡觉赚金币，金币养宠物。" |

## 两个演示加速技巧（路演专属，均已实测）

- **连点宠物 5 下 = 演示加速 ×20**：睡眠分期和整晚流程提速 20 倍（Agent 巡检、
  渐弱、日出计时全部 ÷20），几秒内演完"入睡 → 深睡 → 日出 → 晨间报告"全程，
  路演时不用真等。再连点 5 下恢复常速。2026-11-03 实测触发正常
  （注意：得是真触控/鼠标按下，代码监听的是 pointerdown）
- 掌机**十字键**也能换宠物/调音量，**A 键**夸它、**B 键**开聊天——按出Game Boy的感觉

## 如被追问

- "睡眠数据是真的吗？"——如实答：原型里是模拟分期，接真硬件是单点替换
  （`sim.stage`），固件侧已有时域呼吸率算法（见仓库 `app/mianyu`）
- "语音怎么实现的？"——Web Speech 识别 + TTS + 可选 LLM（OpenAI 兼容接口，
  key 只存本机）；手机上需 HTTPS，脚本已备好
- "数据在哪？"——全部 localStorage 本地闭环，不上传
