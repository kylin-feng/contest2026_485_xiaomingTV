| AMOLED 暗光 | 呼吸光晕上屏，关灯 | 纯黑底 + 暖光，零光污染 | 通过：面板 ReadID=0x331100 对得上、VADD_EN(PA37) / 背光 ON(PA01)、LVGL 线程已起；暗光实拍照片还没拍 | 证据文件第 2 节 |

- [x] 三项都跑了，MIC 和屏幕过，录放卡在硬件上
- [x] 异常项当天就记进 `docs/测试记录表.md` 和证据文件了，没隔夜

### 录放这条的排查结论

软件侧能查的都正常：

| 项 | 状态 |
|---|---|
| `BSP_ENABLE_DAC2` | 只有 LB58X 才定义，LB52 的 DAC2 禁用 —— 设计就是这样，不是 bug |
| DAC1（A.33）输出级 `EN_OS_DAC` | 已开 |
| 功放使能脚 PA10 | pinmux 和运行期都确认置位了 |
| 功放芯片 U0104（NS4150B） | 没有 I²C 之类的可配置项 |
| J0101 上插没插喇叭 | 最可能的原因，得人看一眼 |

复验方法：把喇叭插到 J0101 上，重跑 `sound_card.py`，B/C 比从 0.83 涨到 2 倍以上就算通。
