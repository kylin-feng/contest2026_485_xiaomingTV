### ① 的排查结论与待办

已排除（软件侧全部正常）：

| 项 | 状态 |
|---|---|
| `BSP_ENABLE_DAC2` | 仅 LB58X 定义，LB52 的 DAC2 禁用 —— **设计如此，非缺陷** |
| DAC1（A.33）输出级 `EN_OS_DAC` | 已开 |
| 功放使能脚 PA10 | pinmux + 运行期均确认置位 |
| 功放芯片 U0104（NS4150B） | 无 I²C 等可配置项 |
| **接插件 J0101 是否插了喇叭** | 🔴 **需人工确认**，当前最可能原因 |

> 复验方法：确认 J0101 插上喇叭后重跑 `sound_card.py`；若 B/C 比从 0.83 升到 2× 以上即判定声学通路打通。
